# Python-Numbergussing-Game
A Python-based number guessing game with random number generation and input validation.
# 🎯 Number Guessing Game

## About the Project
This is a beginner-friendly Python game.
The computer generates a random number, and the user
tries to guess the correct number.

## Features
- Random number generation
- User input validation
- Higher or lower hints

## Technologies Used
- Python 3
- Random module

## How to Run
1. Install Python 3.
2. Download the project.
3. Open the terminal.
4. Run the command:

   python number_guessing.py

## Concepts Learned
- Variables
- Loops
- Conditional statements
- User input
- Random module
